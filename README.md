# fadeltd Homebrew tap

```bash
brew install --cask fadeltd/tap/xiaomi-debloater
```

| Cask | Description |
|---|---|
| [`xiaomi-debloater`](https://github.com/fadeltd/xiaomi-debloater) | Remove MIUI and HyperOS bloatware over ADB, without root |
| [`pdfunlock`](https://github.com/fadeltd/pdfunlock) | Unlock password-protected PDF files from the command line |

Casks here are updated automatically by each project's release workflow.
